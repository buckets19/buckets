# 🏀 Buckets

Full-court multiplayer hoops you play in the browser — built for iPads.

**Play:** https://buckets19.github.io/buckets/

- One person taps **Host a game** and gets a 4-letter room code.
- Friends open the same link, type the code, and tap **Join**. 1v1 up to 3v3, add bots to fill teams.
- Hold **SHOOT** and let go in the green. Run at the rim to dunk. **CROSS** to break ankles, **STEAL** is a reach you can get crossed on.
- Earn coins and unlock cellys and green FX in the shop (saved on your device).

Tip: turn the iPad sideways, and the host should keep the game open on screen — the host's iPad runs the match.
